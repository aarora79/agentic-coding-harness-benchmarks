Throughput & cost -- minimax-m3 on p5e.48xlarge

Agentic /swe concurrency sweep. Throughput from vLLM server counters (DuckDB); machine cost = $27.72/hr on p5e.48xlarge. A "task" is a blended 13,812,652 input : 50,825 output tokens (~271.8:1, from real /swe runs). Two cost lenses: blended (Lens A) charges every processed token the same measured GPU-slice; split (Lens B) weights an input token at 0.25× an output token (a lab-style convention, not measured). Cost is hardware-derived, not a per-token bill.
