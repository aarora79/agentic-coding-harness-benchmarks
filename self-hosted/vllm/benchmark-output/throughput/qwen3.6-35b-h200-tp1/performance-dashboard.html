Agentic /swe concurrency sweep. Throughput from vLLM server counters (DuckDB); machine cost = $5.1428/hr on p5en.48xlarge. A "task" is a blended 1,510,243 input : 30,359 output tokens (~49.7:1, from real /swe runs). Two cost lenses: blended (Lens A) charges every processed token the same measured GPU-slice; split (Lens B) weights an input token at 0.25× an output token (a lab-style convention, not measured). Cost is hardware-derived, not a per-token bill.
