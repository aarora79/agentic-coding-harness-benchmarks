Throughput & cost -- qwen3-coder-480b on p5en.48xlarge

Agentic /swe concurrency sweep. Throughput from vLLM server counters (DuckDB); machine cost = $27.46/hr on p5en.48xlarge. A "task" is a blended 4,276,703 input : 11,348 output tokens (~376.9:1, from real /swe runs). Two cost lenses: blended (Lens A) charges every processed token the same measured GPU-slice; split (Lens B) weights an input token at 0.25× an output token (a lab-style convention, not measured). Cost is hardware-derived, not a per-token bill.

Tip: click any point on a chart for that concurrency level's full numbers.
