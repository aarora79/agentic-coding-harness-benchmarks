# Release 0.5.0 - Opus 5.5 on the Strands harness

**October 2026**

Version bump: **MINOR** -- adds Claude Opus 5.5 to the `strands-harness` `/swe3` frontier. Nothing else changed: no code, no config, and no published score or cost from 0.4.0 moved.

---

## Upgrading from 0.4.0

This repo is cloned and run, not deployed, so upgrading is a pull.

```bash
git pull origin main
git checkout 0.5.0
```

No dependency changed, so neither `uv` project needs a sync. The `swe-router` skill is byte-for-byte the same as in 0.4.0: `models.json` is built from the omp frontier alone, and `build_vended_models.py --check` passes. An installed skill needs no upgrade.

### Methodology changes

None. Numbers remain comparable with 0.4.0. The only frontier file that changed is [pareto-frontier-strands-harness-swe3.json](../metrics/pareto-frontier-strands-harness-swe3.json), which gained `claude-opus-5-5`; no existing entry in it moved.

### Config changes

No configuration changes in this release.

## New models

### Claude Opus 5.5 on strands-harness / mcp-gateway-registry-v2

**80.80 for $2.42 a task**, 21 of 21 tasks scored, every one with all six artifacts on the first attempt. The run used `us.anthropic.claude-opus-5-5` on Amazon Bedrock under `--agent strands-harness`, the Strands team's `create_harness()` agent, and the judge was `openai.gpt-5.6-sol` at high effort. The loop guard never fired. Source: `benchmarks/swe-benchmark-data/claude-opus-5-5/strands-harness/swe3/mcp-gateway-registry-v2/run-summary.json`.

The same model on the same 21 tasks under the other harnesses:

| Harness | Score | Cost per task |
|---|---:|---:|
| strands-harness | 80.80 | $2.42 |
| strands | 81.21 | $2.46 |
| omp | 81.16 | $4.44 |

The three land within 0.41 points of each other, which is noise on 21 tasks run once. Both Strands builds cost about 55% of omp per task.

It joins both the combined and the Bedrock frontier for this harness, at the top of each. The combined frontier is now `minicpm5-2b`, `claude-haiku-4-5`, `claude-sonnet-5-5` and `claude-opus-5-5`; the Bedrock frontier is the last three.
